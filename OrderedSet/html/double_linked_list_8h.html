ListStatus deleteCurrent ( DoubleLinkedList * list)

◆ insertAfter()

ListStatus insertAfter ( DoubleLinkedList * list,
int newData )

Inserts a new node holding newData after the current node.

The list uses dummy head and tail nodes, so nothing can be inserted after the tail. The current node is not changed by this operation.

Parameters
listValid double linked list
newDataValue to store in the new node
Returns
LIST_OK on success, LIST_ERROR if current is the tail, LIST_ALLOC_ERROR if memory could not be allocated
