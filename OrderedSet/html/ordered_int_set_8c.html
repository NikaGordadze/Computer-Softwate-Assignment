SetStatus addElement ( OrderedIntSet * s,
int elem )

Adds elem to the ordered set at its sorted position.

The list is kept in ascending order, so the list is searched for the first node whose value is >= elem and the new node is inserted just before it. Duplicates are rejected.

Parameters
sValid ordered set
elemValue to add
Returns
NUMBER_ADDED if elem was added, NUMBER_ALREADY_IN_SET if it was already present, ALLOCATION_ERROR if a new node could not be created

OrderedIntSet * setDifference ( OrderedIntSet * s1,
OrderedIntSet * s2 )

Computes the difference s1 - s2 of two ordered sets.

Walks both sorted sets side by side. An element of s1 is copied into the result only if it is not found in s2. Neither s1 nor s2 is modified.

Parameters
s1set to take elements from
s2set whose elements are left out
Returns
new set with all elements in s1 but not in s2 (empty set if s1 and s2 are equal), or NULL on allocation error

◆ setIntersection()

OrderedIntSet * setIntersection ( OrderedIntSet * s1,
OrderedIntSet * s2 )

Computes the intersection of two ordered sets.

Both sets are sorted, so they are walked side by side (like the merge step of merge sort): whichever current value is smaller is skipped, and equal values are copied into the result. Neither s1 nor s2 is modified.

Parameters
s1first set
s2second set
Returns
new set with all elements in both s1 and s2 (empty set if there are none), or NULL on allocation error

Computes the union of two ordered sets.

Copies every element of s1 and every element of s2 into a new set. addElement() already rejects duplicates, so no element appears twice. Neither s1 nor s2 is modified.
