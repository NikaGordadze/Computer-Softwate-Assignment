void loadSetsOption ( OrderedIntSet * setsArray[])

loadSetsOption (menu 6) Loads the entire SetsArray from "SetsArrayFile.bin".

The file is first read into a temporary array. Only if the whole file was read successfully, the old sets are deleted and replaced by the loaded ones.

Parameters
setsArrayarray of MAX_SETS pointers to ordered sets

◆ storeSetsOption()

void storeSetsOption ( OrderedIntSet * setsArray[])

storeSetsOption (menu 5) Stores the entire SetsArray in "SetsArrayFile.bin".

File format: for each of the MAX_SETS entries an int flag (0 = no set, 1 = set present). If the flag is 1, an int with the number of elements follows, followed by the elements (ints) in ascending order.

Parameters
setsArrayarray of MAX_SETS pointers to ordered sets
